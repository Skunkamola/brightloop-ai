# Security policy

BrightLoop is an early-stage local-first tool. Treat all model output as untrusted.
The current release only supports creating new Markdown notes and appending to a
local Markdown log. It does not execute shell commands, run arbitrary code, or
send messages to external services.

Please do not publish API keys, personal data, or private workspace files in bug
reports. Report security concerns privately to the repository maintainer once a
security contact is configured.
